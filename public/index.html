A NOTE ON EVIDENCE

Stale is a fact.
Impact needs context.

Ravel detects when an agent writes after one of its directly observed resources changes. Every write inherits candidate provenance from the current task attempt's observation frontier.

Downstream means an artifact descends from stale-derived work. It does not prove that artifact is incorrect. Dashed version-succession lines are excluded from the blast radius.

This demo uses scripted agents and a narrow semantic rule for the INTEGER → UUID migration. The rule is labeled in the inspector. General model-based analysis and real agent adapters are not connected yet.

Only operations mediated by the runtime are covered. Replay shows stored events; Repair creates new task attempts and preserves historical findings.
